VineTrack Beta v16 — GitHub + Railway Upgrade Guide
===================================================

IF V15 IS ALREADY LIVE
----------------------
1. Unzip this V16 package on your Mac.
2. Open the existing GitHub VineTrack repository.
3. Add file -> Upload files.
4. Upload the CONTENTS inside this V16 folder to the repository root.
5. Commit with a message such as: Upgrade VineTrack to Beta v16.
6. Railway should redeploy automatically from GitHub.
7. Keep the existing /data volume and existing variables.

NEW V16 AMAZON SIGN-IN VARIABLES
--------------------------------
Add these to the SAME Railway VineTrack service:

VINETRACK_AMAZON_CLIENT_ID=<your Login with Amazon client ID>
VINETRACK_AMAZON_CLIENT_SECRET=<your Login with Amazon client secret>
VINETRACK_AMAZON_REDIRECT_URI=https://YOUR-LIVE-DOMAIN/auth/amazon/callback

Do not place the client secret in GitHub.

LOGIN WITH AMAZON CONFIGURATION
-------------------------------
In your Login with Amazon application/security profile, add this exact Return URL:

https://YOUR-LIVE-DOMAIN/auth/amazon/callback

It must exactly match VINETRACK_AMAZON_REDIRECT_URI.

EXISTING VARIABLES
------------------
VINETRACK_DB_FILE=/data/vinetrack.db
VINETRACK_FEEDBACK_FILE=/data/feedback.jsonl
VINETRACK_ADMIN_KEY=<private admin key>

Existing volume mount:
/data

ROOT DIRECTORY
--------------
If Dockerfile and server.py are visible directly on the GitHub repository first page,
leave Railway Root Directory blank.

TEST AFTER DEPLOYMENT
---------------------
1. Open /health and confirm app = VineTrack Beta v16.
2. Confirm amazon_signin_configured = true.
3. Open the home page.
4. Click Continue with Amazon.
5. Complete Amazon sign-in and return to the VineTrack dashboard.
6. Sign out and repeat once.
7. Test Chrome extension connection after Amazon sign-in.
